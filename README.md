# The Spice Studio — Liquid Glass Edition

A responsive, single-page static restaurant website using the supplied logo, restaurant photographs and hero video.

## Run locally
Open this folder in VS Code and use Live Server, or run a local static server:
`python -m http.server 8000`

Then visit `http://localhost:8000`.

## Deploy
Upload the contents of this folder to any static hosting provider (Netlify, Vercel static deployment, GitHub Pages, or your own web server). Keep the `assets` folder beside `index.html`.

## Before launch
- Replace the placeholder business email in `index.html`.
- Replace Facebook and Instagram placeholder links with the restaurant's real profiles.
- Forms open WhatsApp with the entered details; the customer must press Send in WhatsApp.
- Test the forms, navigation, map and phone links on a real phone before publishing.

No prices or operating hours are displayed. No PDF menu is included.
